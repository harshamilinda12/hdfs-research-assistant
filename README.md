# HDFS Session-Level Log Anomaly Root Cause Localization — Research Assistant

A learning project building an agentic RAG system to assist undergraduate research on
Parameter-Aware Root Cause Localization for Session-Level Log Anomalies in HDFS.

## Status
Phase 0 — project setup

## Stack
LLM: Groq API (free tier)
Embeddings: sentence-transformers (local)
Vector store: Chroma
Web search: TBD

## Setup
1. python -m venv venv
2. Activate venv
3. pip install -r requirements.txt
4. Copy .env.example to .env and add your Groq API key
